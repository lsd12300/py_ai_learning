
# AI Agent

## 两种模式

### 1. ReAct 模式
边做边想.
让 AI 反复执行三步循环 (Think -> Act -> Observe), 直到任务完成.

### 2. Plan-Execute 模式
先计划, 再执行.

## 两种模式的区别

决策方式:
- ReAct 模式: 边做边想. 每步实时决定
- Plan-Execute 模式: 先整体规划, 再逐步执行.

适合场景:
- ReAct 模式: 开放问题, 不确定性高, 每步结果会影响下一步决策.
- Plan-Execute 模式: 结构清晰, 步骤可预见.

用户参与:
- ReAct 模式: 全自动.
- Plan-Execute 模式: 可以让用户确认计划, 再执行.
